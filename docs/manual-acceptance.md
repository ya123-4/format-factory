# 格式工厂（自用版）手动验收清单

阶段一验收（对应 spec §1.3 成功标准）。在**普通桌面环境**执行（双击 bat，非 DSH 沙箱终端）。

## 准备

1. 一个真实的 `.vdat` 样例文件（行车记录仪等设备导出）。
2. 各一个测试文件：视频（mp4）、音频（flac 或 mp3）、图片（bmp 或 png）、文档（docx 或 xlsx）。

## 检查项

- [ ] 1. **vdat → mp4**（核心诉求）：添加 `.vdat` 文件 → 目标格式 mp4 → 转换成功 → 用播放器打开产物可正常播放。日志无「已降级重编码」提示即为无损流复制。
- [ ] 2. **视频转换**：mp4 → mkv（应显示秒转，同源无损）；mp4 → webm（自动降级重编码，日志有提示且转换成功）。
- [ ] 3. **音频转换**：flac → mp3 成功可播放。
- [ ] 4. **图片转换**：bmp → png、bmp → jpg 成功，图片可打开。
- [ ] 5. **文档转换**：docx → pdf 成功且 PDF 内容完整；xlsx → csv 内容含原单元格数据。
- [ ] 6. **文件夹递归**：建 `视频/旅行/` 两级目录放视频，添加父文件夹 → 输出目录下出现 `视频/旅行/` 子目录结构。
- [ ] 7. **批量 + 失败隔离**：混合添加一个正常文件和一个损坏文件（如把文本改名 .mp4）→ 正常文件转换成功，损坏文件标红显示失败原因，队列不中断。
- [ ] 8. **冲突策略**：同目录重复转换同一文件 → 产物自动命名 `name_1.ext`；配置切「跳过」→ 第二次转换该行显示「跳过」且汇总单列。
- [ ] 9. **停止**：添加一个较大的视频开始转换 → 点「停止」→ 当前任务终止、剩余任务「已取消」、无 `.part.*` 残留文件、已完成结果保留。
- [ ] 10. **中文路径**：源文件路径含中文和空格（如 `我的 视频/test 文件.mp4`）→ 转换成功。
- [ ] 11. **再次开始**：失败/取消行不自动复活；右键「重新转换」后行回到「待转换」，点开始只跑待转换项。
- [ ] 12. **日志与配置**：`%APPDATA%\FormatFactory\logs\conversions.log` 有转换记录；改动输出目录后 `config.json` 内容更新。
- [ ] 13. **双击启动**：关掉后双击 `格式工厂.bat` 重新打开，无控制台黑窗。

## 通过标准

全部勾选即阶段一验收通过，可进入阶段二（PyInstaller 打包 exe）。任何一项失败请记录现象与日志文件内容反馈。
